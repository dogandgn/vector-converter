# Teknolojiler

| Bileşen | İşlev |
| --- | --- |
| Python / PyQGIS | Dosya inceleme, geometri, koordinat dönüşümü ve QGIS görevleri |
| Qt / qgis.PyQt | Pencereler, tablolar, seçimler ve ilerleme göstergeleri |
| GDAL/OGR | Vektör veri sürücüleri ve yeniden okuma doğrulaması |
| SQLite, JSON, XML, HTML | İç veri modeli, çıktı, rapor ve çevrimdışı yardım |

Çalışma bileşenleri QGIS kurulumundan alınır. Ayrı modül kurulumu veya çevrimiçi hesap gerekmez.
